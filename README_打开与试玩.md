# 裁星计划 · BY冻橙更新版 · 1–4关 Demo
本目录是Unity工程根目录，包含Assets、Packages和ProjectSettings。使用本机Unity 2022.3.62f3c1：Unity Hub → 添加磁盘中的项目 → 选择本目录 → 打开。运行 `Assets/Siderectomy/Scenes/MainMenu.unity`，或菜单“裁星计划 → 打开开始界面”，即可体验新建存档、设置、继续游戏与退出游戏。Windows试玩版在 `Builds/WindowsDemo/裁星计划Demo.exe`，默认进入开始界面。直接运行 `StarSystemTest.unity` 仍可调试1–4关。
## 试玩流程
经济建设 → 军工制造 → 隐形探测卫星研发 → 信号捕捉 → 制造武装与信息 → 制造载体 → 星系探测 → 深度侦察 → 选中城市或中心 → 发射。初始暂停，点击“继续”或空格后所有队列开始推进，支持1×、2×、4×。比如先做星尘载体，再切到“作业投送”发射星系探测，确认轨迹后才能深度侦察；侦察后，右侧中心按钮可以指定伤害目标，城市按钮负责人口伤害。右侧详情、中心列表和作业进程均支持滚轮。
开局星图现在为基本全黑的未知区域，只保留作业基地、扫描提示与玩家操作界面；天体数量、名称、轨道、目录和关联预览均隐藏。右侧“探测星系”入口准备现有扫描作业，首次扫描无需先选中未知星球，仍需制造载体并支付原有探测费用。扫描在途 → 星系保持未知 → 作业完成 → 揭示全部天体与轨道并开放目录、预览和局部入口 → 深度侦察再揭示单一天体的人口、中心与备份。切换关卡或重新开始会重新隐藏星系，暂停或进出视图不会自行完成探测。揭示门槛由新增 `DemoSystemDiscovery.cs` 统一读取原有 `GlobalProbe` 完成状态，不设置第二份探测状态或计时。
## 四关内容
第一关为1恒星、3行星、1卫星的低文明教学，144P集中在卫星，480秒，关闭察觉与主动扩建，仅解锁基础生产、探测、侦察和地表打击。第二关为1恒星、3行星、3卫星、2人工天体，540P分布在3颗行星，720秒，开放造访、入侵、二级武装、行星与卫星打击，功能中心集中在主星。第三关为1恒星、5行星、5卫星、3人工天体，1050P分布在3颗行星，840秒，能源军工与政治信息分置双核心，解锁三级武装、行星载体及恒星打击。前三关任何外逃舰离开星系立即失败；前3关的具体人口、中心与时间是为本Demo补齐的临时数值，可在配置里调节。
第四关严格采用实时HTML太阳系基准：1恒星、8行星、10卫星、3个空载轨道站，地球1536P、月球114P，全部25个功能中心集中地球，960秒，初始能源150、物质150、信息12、一级武装28。初始中心摧毁18个后解除人口保护，解除前最多消除495P。外逃人口转为第二结局记录，不计入星系剩余人口；在途人口仍须处理，拦截后返回原天体。备份残留、累计暴露和熵增进入评分，外逃与备份不阻断第四关通关。
## 画面与操作表现
沿用HTML深色星图、压缩椭圆轨道、底部资源储备与七类可滚动操作、右侧天体详情的布局，加入实时天体运动、载荷飞行轨迹、命中扩散圈、外逃舰飞离与目标选中环。地球、其他行星、卫星、空间站复用原工程 Earth、Backup、Satellite 图片占位，星空与办公室角色沿用原图片，所有原美术文件及导入设置均保留。投送期间点击“接管”可做时机校准，成功效果+20%并缩短5秒，失败效果−20%且察觉+3，小游戏暂停战场。研发自动按HTML的A档完成。
## 2026-10-10 局部视图、关联预览与指定阻截
单击天体仍可在右侧查看详情并直接安排投送，“进入局部”为可选入口；局部图展示母星、关联卫星及轨道站，侦察后显示该天体的中心节点。点击节点与点击右侧中心列表使用同一目标ID，右侧“当前查看”显示选中天体、中心或外逃舰及上一级单位。深度侦察完成 → 揭示中心 → 图标或列表选中 → 支付原有费用并进入原有投送队列 → 到达后扣除对应耐久；已毁中心不能再次作为目标。天体目录保留全部对象，当前视图未绘制的天体也可选择。返回总览与进入局部只切换画面，不重置时间、资源、队列和损伤。
关联预览整合在右侧顶部，和主图使用同一模拟时钟。未侦察天体只展示外观及关联对象，人口、中心耐久、备份和主要威胁显示“待侦察”；态势栏只统计已侦察天体的数据，未知中心与AI建造详情不会通过日志显示。
外逃舰使用椭圆弧航迹，可点击舰船图标或右侧舰船目录选中；选中后自动准备“拦截外逃舰”，发射仍消耗原有费用与一个载体。作业绑定发射时选中的舰船ID，后续换选不会改变目标，目标提前离场后不会误拦其他舰船。自然生成的外逃舰离场窗口由30改为60游戏秒，由关卡配置中的 escapeFlightSeconds 控制；1×/2×/4×仍推进同一模拟时间。拦截后人口返回出发天体，前三关外逃即失败、第四关外逃记录第二结局的结算口径保留。
补充规则验收见 `Docs/Validation/规则验收.txt`，实际界面点击与渲染验收见 `Docs/Validation/LocalInteraction`。交互验收使用独立的资源充足夹具，但探测、侦察与打击均通过普通付费队列完成，不代表完整真人难度平衡。
## 调试与架构
菜单“裁星计划 → 选中1–4关参数”选中 `Assets/Siderectomy/Resources/DemoCampaign.asset`，四关数值可直接在 Inspector 中调整，保存后再次运行生效。运行时“基准调参”只影响本次重开的当前关卡。生产、载体、操作与AI规则集中于 `Resources/DemoRules.json`，由HTML规则表提取；`DemoSimulation` 独立处理经济、并行队列、伤害、保护、AI与胜负，`DemoMissionView` 负责界面与本地存档，`DemoStarMap` 负责星图和飞行表现。旧最小模拟器不参与新Demo；原工程保留在同级原始评审包目录。
## 依据与差异
采用用户指定HTML原型的当前效果，结合Excel关卡规模与数值体系资源层级。Excel第三关提及星系打击，但HTML当前规则明确锁定第五关，本Demo保持第五关锁定。Excel包含的其他远期行为与完整研发解密、申请对话小游戏不作为当前HTML效果加入；申请保持25秒随机资源拨付，累计次数本地保存，第二结局本地记录。1P沿用策划尺度，表示10万个体；图上压缩距离不作为伤害范围。

## 物资储备HUD与图标替换
状态栏现在持续显示四种载体、三项科技、三级武装、六类打击模块；科技按已研发0/1显示，制造和研发中的任务单独标记，未解锁项显示灰色。点击任一物资可查看储备说明，并直接前往制造、研发或预装配。
打击模块支持提前预装配：支付原有作业费用 → 立即入库 → 发射优先扣除1个模块与1个载体。库存为空时仍按原有费用即时装配并发射；预装配库存不重复收费，隐形附加费用仍在发射时计算，失败发射不扣库存。
用户提供的图片保存于 `Assets/Siderectomy/Art/HUD_代替换`，原始字节保留；载体图集使用Sprite切片，科技使用芯片图，武装和模块暂复用单枚火箭图。`Assets/Siderectomy/Resources/HUD图标配置_代替换.asset` 中的16个槽位可以直接拖入新Sprite进行替换。菜单“裁星计划 → 创建或选中HUD图标配置”可定位该配置，已有配置不会被覆盖。
策划补充位于原策划案“工作表1”第92–104行，包含显示口径、入库与消耗、解锁、点击详情、布局和替换方式；项目参考文件同步更新，并保留HUD补充前备份。

## 2026-10-12 分区、通讯与存档更新
星图左上角为自下向上更新的浮动日志，淡入后完整停留3秒再淡出；底部左侧分类和操作选项使用滚动窗，卡片预留UI图标框，右下角为通讯员。点击形象改变颜色并展开AAA、BBB、暂停键，前两项展示对应回复，暂停键进入局内暂停菜单。顶部办公室按钮和Esc也可进入暂停菜单。
新建存档 → 办公室 → 选择模拟关卡；保存模拟进程并退出 → 办公室 → 继续已保存的模拟，或开始界面“继续游戏” → 选择档案载入。读档后现场暂停，点击继续后才推进；在途任务、队列、伤害、库存、科技、计时和随机状态随档案保存。重新模拟和放弃退出会清除当前局内记录，删档在存档列表操作并二次确认。
详细规则与文件位置见 `Docs/2026-10-12_界面分区与存档说明.md`；自动化规则与实际画面验收记录位于 `Docs/Validation/LayoutSave`。改造前脚本备份位于 `Docs/Backups/2026-10-12_分区与存档改造前.zip`。
