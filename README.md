# 裁星计划 / PROJECT SIDERECTOMY

Unity 2022.3.62f3c1制作的六关GameJam试玩工程，包含办公室、星系探测、碳基与硅基文明、模块制造与组合投送、太阳系剧情和本地存档。

新版采用逐关解锁：新档从第1关开始，完成目标后解锁下一关，已解锁关卡可重玩。旧档保留原位置，包括第5、6关。验收线性流程请新建档案。

## 试玩

下载并解压仓库后，双击根目录的 `启动Demo.cmd`，或运行 `Builds/WindowsDemo/裁星计划Demo.exe`。保留整个WindowsDemo目录；无需安装Unity。开始界面选择“创建新存档”，在办公室选择第1关或接入终端。角色使用A/D移动、E交互；局内初始暂停，按空格或点击继续推进时间。

试玩版保留基准调参和现有功能权限调试，方便策划评审。存档、生产、投送和剧情机制沿用六关模块改版。

用Unity Hub添加仓库根目录，使用Unity 2022.3.62f3c1。菜单“裁星计划 → 打开开始界面”后播放；菜单“验证并构建Windows Demo”可重新构建运行版。
