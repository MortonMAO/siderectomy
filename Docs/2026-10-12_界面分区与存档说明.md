# 2026-10-12 界面分区与存档
星系上方保持目标选择与观察，日志浮层位于星图左上角。新消息从底部加入 → 原消息向上移动 → 0.25秒淡入 → 不透明停留3秒 → 0.6秒淡出；最多并列4条，暂停时仍按现实时间播放。右侧保留目标、关联预览与作业信息，作战日志已移出；未完成侦察的信息仍按原规则隐藏。
底部操作区域宽1080，右下角通讯区域宽510。一级分类支持横向滚动，分类内选项支持纵向滚动；作业投送的下拉选项也可滚动。生产、研发、载体和打击卡片统一使用DemoOptionCard，每项均有UIIcon_代替换图像槽。物资HUD保留四类库存的持续显示。
点击通讯员形象 → 占位色改变并提示接入 → 展开AAA、BBB、暂停键。AAA与BBB显示对应演示回复；暂停键进入真正的暂停菜单。再次点击通讯员可收起对话。当前通讯仅为本地交互演示。
暂停菜单可由通讯员的暂停键、顶部办公室按钮或Esc进入。重新模拟 → 放弃当前现场并以当前关卡参数重开；放弃模拟进程并退出 → 清除该档案的局内记录，回办公室；保存模拟进程并退出 → 写入完整现场，回办公室；返回模拟 → 恢复进入菜单前的暂停状态。写入失败时保留现场并显示原因。
开始界面包含创建新存档、设置、继续游戏、退出游戏。新档案 → 办公室 → 选择1–4关或接入终端；继续游戏 → 存档列表 → 载入办公室或局内记录。删档必须二次确认，删除时同时删除该档案备份。办公室有局内记录时可直接继续模拟，其他关卡按钮暂时禁用，避免覆盖该现场。
局内存档保存关卡参数、全部资源与库存、研发、生产队列、在途作业、舰船、文明节点耐久、AI设施和队列、病毒、效果、随机状态、计时、已选对象和局部视图、当前操作分类与投送选择。读档后强制暂停，等待玩家确认继续；离线时间不推进模拟。各档案彼此独立，新档案不继承旧的全局PlayerPrefs申请次数。
文件位于Application.persistentDataPath/Saves；在本机常规Windows安装下为用户AppData/LocalLow/BY冻橙更新版/裁星计划 1–4关 Demo/Saves。JSON使用版本和校验值，覆盖保存采用临时文件替换并保留上一版.bak；损坏档案在列表标记，可恢复备份或删除。测试使用独立TestSaves目录，不接触真实玩家存档。
打开Assets/Siderectomy/Scenes/MainMenu.unity运行开始界面，也可使用Unity菜单“裁星计划→打开开始界面”。Windows试玩程序默认从开始界面启动；直接打开StarSystemTest.unity仍可调试第四关，首次保存时会建立调试档案。
