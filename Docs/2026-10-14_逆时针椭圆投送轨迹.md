# 逆时针椭圆投送轨迹
后续更新：基地已改为右下角，玩家航线已改用围绕星系中心的椭圆巡航与平滑轨道转移，避免穿过恒星。本文件关于中点椭圆的实现说明属于历史记录，请以《2026-10-14_右下基地与绕星轨道转移.md》为准。
修改工程：siderectomy-v2 - 本地修改版内的Unity项目。玩家投送从作业基地出发，沿逆时针椭圆弧抵达目标；自然天体、卫星和外逃舰目标均适用。总览与局部视图共用同一套轨迹函数，右上关联预览仍不绘制玩家任务。

轨迹由起点和目标点作为椭圆长轴两端构造，角度递增0→π，法线采用逆时针方向；曲率受到星图边界约束，避免下缘和侧边的航线离开画面。位置使用开普勒方程E−e·sin(E)=M映射投送进度，呈现近点快、远点慢的节奏。路径线和移动标记分别按几何参数与时间参数采样，不再用直线插值。

这是星图上的椭圆转移弧表现近似，焦点不强制位于太阳；目标点仍跟随天体或外逃舰在当前视图的位置，因此不是完整的引力、多体运动或真实轨道交会模拟。此次沿用作业倒计时，不修改资源消耗、投送时长、命中和伤害、关卡解锁或存档数据。

实现入口：Assets/Siderectomy/Runtime/DemoTransferOrbit.cs负责曲线、边界与时间映射；DemoStarMap.cs负责采样航线与移动标记。曲率默认为长半轴的45%，上限140星图单位，再按边界缩小。起点与目标重合时保持稳定，零时长任务不会除零。

验证入口：Unity菜单“裁星计划 → 验证椭圆投送轨迹”，检查多个方向的椭圆方程、逆时针叉积、边界、起终点及开普勒映射；批处理DemoOrbitChecks.Build同时验证已有模块机制并构建Windows版本。运行参数--orbit-ui-check后接独立目录，可生成总览、三个运动阶段和局部/拦截截图，采用暂停和任务夹具，不写入真实玩家存档。
