# 模块制造与投送改版
当前入口：Builds/WindowsDemo/裁星计划Demo.exe。T“模块制造”分为打击模块与科技模块，E制造载体，Y按“选择载体 → 搭载 → 发射”操作。扫描与深度侦察保留为Y中的基础操作，允许附加隐形；入侵可单独投送，也可与一个打击模块合并为一次投送。
切换到制造窗口再返回投送，会保留载体、打击与科技模块的搭载草稿，选择不等于占用库存。库存只在发射成功时扣除；其他任务先消耗库存后，当前投送会重新校验。模块制造卡片和投送下拉显示当前库存。

搭载能力用capacityRank单独判定，不以总槽数比较；因此小行星级能运载行星打击，却不能同时装隐形和入侵。各模块只能装一个，不能用科技槽额外装打击模块。比如卫星级可以装地表打击+隐形+病毒，但星尘级只能装地表打击+一种科技；行星级虽有3科技槽，信息入侵和病毒的目标文明不兼容，当前没有可以同时使用两者的单一天体。

制造扣能源和对应材料 → 队列倒计时完成 → 模块库存增加 → 搭载 → 发射消耗一个载体和每种模块各一个。发射不重复扣制造费，也不再库存为空时即时装配；制造中的模块不能发射。失败的容量、目标文明、权限或库存校验不扣资源。扫描和侦察按原作业费用直接扣费，不作为新增模块制造。组合投送总时间为载体航行时间+所有所选效果中最长执行时间，各效果共同抵达；不会为附加科技再次消耗载体。

隐形统一为一种科技模块，替代原信息扰动与物理检测隐形。信息入侵只影响硅基链流速，已取消原“信息病毒”的备份清除附带效果；病毒只作用碳基人口。移除信息扰乱、信息窃取、信息病毒旧项目、分子结构解离、星系级打击及结构解离研发。调试全开也不会恢复已删项目。三级武装资源与生产保留兼容，但当前模块费用按本次要求只读取能源+物质或能源+信息，武装库存不再作为模块制造的消耗。

配置入口：Assets/Siderectomy/Resources/DemoRules.json。carriers的attackSlots、technologySlots、capacityRank控制插槽和能力；operations与modules的moduleType分类，manufactureSeconds为制造入库秒数，seconds为抵达后执行计时口径，cost为制造费用；伤害、节点血量、病毒周期和信息流持续时间仍读取原配置字段。隐形immuneCounter控制免反制，alert控制察觉修正。修改配置后需重开本局，Windows构建需重新打包。
