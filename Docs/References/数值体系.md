# 数值体系

## 玩家端

### 一级资源

- 能源
  
- 物质
  
### 二级资源（用一级资源制造）

- 武装
  
    - 一级武装
      
    - 二级武装
      
    - 三级武装
      
- 信息
  
### 消耗品（消耗能源、物质、武装、信息制造，一次性，发射即消耗）

- 运输载体
  
    - 星尘级别
      
    - 卫星级别
      
    - 小行星级别
      
    - 行星级别
      
- 打击武器
  
    - 地表设施打击：消耗物质、一级武装
      
    - 行星打击：消耗物质、一级武装、二级武装
      
    - 卫星打击：消耗物质、二级武装
      
    - 恒星打击：消耗物质、二级武装、三级武装
      
    - 星系级别打击：消耗物质、三级武装
      
- 搭载技术
  
    - 探测类
      
        - 探测星系情况（掌握星系部分情况）
          
        - 侦察特定天体（掌握指定天体的全部情况）
          
    - 反制类
      
        - 信息扰乱
          
        - 信息窃取
          
    - 入侵类
      
        - 病菌入侵
          
    - 隐形类
      
        - 信息扰动隐形
          
        - 物理检测隐形

- 人口（天体上的人口清零）

- 结构完整度（低级文明的结构完整度仅仅局限于单个/两三个天体内的各个功能节点）
