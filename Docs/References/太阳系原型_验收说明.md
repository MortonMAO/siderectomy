# 第四关太阳系验收
打开《裁星计划_实时原型.html》即可离线运行。初始为暂停，点击底部“继续”开始计时。布局对应参考图：左上星图、左下资源与全局操作、右侧天体详情及目标操作。星图使用压缩轨道，距离说明显示真实 AU，不以图上距离作为伤害范围。
经济起手：能源采集器 → 物质转化器 → 军工制造点 → 隐形探测卫星研发 → 信号捕捉点。能源和物质按秒增长；一级/二级/三级武装、信息每次制造都扣除能源与物质，并占用对应设施的一条队列。三档武装不自动转换，制造完毕后进入独立库存。
投送操作：制造运输载体 → 选中天体 → 选择作业和载体 → 选配隐形模块 → 发射。探测、深度侦察与打击均消耗载体库存，载荷和模块另行扣费；星系探测确认轨道，深度侦察揭示该天体人口、中心 HP、信息备份与生命类型。城市目标承接人口伤害，中心按钮承接定点节点伤害，恒星打击同时对所有中心和全星系人口结算。
太阳系基准：960 秒、1650P、25 个初始中心，摧毁18个中心解除人口保护。人口仅存在于地球1536P和月球114P；政治、军事、能源、信息中心全部位于地球，信息备份及AI设施也仅挂靠地球中心。其他行星、卫星与三个轨道站人口和中心均为零，轨道站只保留为可选地图实体。保护解除前最多消灭初始人口的30%，保护解除后可以清零。人口单位1P代表10万个体，只作为策划尺度；调节总人口时维持地球和月球的分配比例。
AI反馈：玩家发射会增加察觉；首次达到30/60/85分别追加6/12/18科技，升级反制与备份效率；达到60或科技70后启动外逃。AI按警戒区间选择能源、军工、冷库、协作或外逃港，挂靠中心被毁则设施失效并取消对应建造。当前察觉可回落，已积累科技、完成设施及外逃记录持续保留。
外逃与胜负：舰船离港后30秒飞出，可使用卫星载体执行“拦截外逃舰”。被阻截的人口返回原天体，仍需清理。已外逃人口独立记录第二结局，不计入当前星系待清人口；在途舰船人口计入待清人口。因此“外逃成功”可以和第四关通关同时成立。胜利仅要求星系及在途人口清零且未超时，信息残留进入评分。
调参入口：右上“基准调参”可以修改时限、人口、节点门槛、基础产率、玩家伤害、AI倍率、科技速度与外逃准备时间，应用后重开本关。该版本只接入第四关，不提供前后关卡选择。参数暂为内存配置，刷新网页恢复草案值；申请次数和第二结局标记存在本地存档。
草案一致性修订：第二关已有卫星打击但二级武装原标第三关解锁、第三关已有恒星打击但三级武装及行星载体原标第五关解锁，本原型以武器可用关卡为准提前依赖制造权限。第四关开放A1/A2/A3与行星载体，星系级打击仍锁到第五关。研发自动结算为A档，投送可选时机校准接管；完整研发S/A/B/C解密小游戏尚未接入。
验证涵盖：初始人口与节点汇总、资源批次制造、侦察揭示、载体一次性消耗、第四关星系打击锁定、范围中心伤害、暂停停止计时、外逃分支、人口守恒、带外逃通关、超时失败与浏览器脚本错误。12–18分钟的完整玩家节奏尚需实际试玩标定，这些检查不等同于最终难度平衡。
