# 右下基地与绕星轨道转移
本地修改版的作业基地已移至星系地图右下角：距地图右边60单位、底边45单位；基地图标、名称、未知星系界面和所有玩家投送共用同一起点。

当前航线：右下基地出发 → 接入最外侧已绘制的椭圆轨道 → 逆时针巡航 → 平滑转入目标轨道 → 接近目标。巡航段使用与星图完全相同的中心、横轴和纵轴；卫星和空间站优先沿所属行星轨道巡航，再靠近实际目标。局部视图采用该视图中心与轨道比例，不套用总览坐标。外逃舰拦截同样从基地出发，并跟随目标当前显示位置。

以星图中心的极角递增保证逆时针，短角度目标补足绕行角度，防止直接抄近路穿过中心。太阳周围保留28单位的安全半径；恒星自身作为目标时，航线在恒星外缘结束，不穿入恒星核心。局部中心天体保留22单位的避让范围。外侧轨道和目标轨道之间采用平滑径向转移，因此完整航线是相接的椭圆巡航与转移弧，不是一条固定椭圆，也不是真实引力交会求解。

运动进度按扫过面积近似分配，外侧巡航较慢，接近内侧轨道加快；作业倒计时、制造、伤害与结算不变。航线还受到地图边界约束。实现位于DemoTransferOrbit.cs的DemoOrbitRoute、DemoStarMap.cs和DemoMissionView.cs的基地标签定位。上一版“以起终点中点为椭圆中心”的航线已不再用于玩家投送。

验证入口仍为DemoOrbitChecks.Build：新增128组目标方位验证，检查右下起点、轨道贴合、逆时针、地图边界及恒星避让，同时保留模块机制回归。--orbit-ui-check参数后接独立目录可生成总览、多个运动阶段、局部和拦截截图；该验收使用任务与侦察夹具，不修改真实存档。
