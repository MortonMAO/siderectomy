# 双阶段建档与个人AI调用ID（2026-10-15）

修改仅在“siderectomy-v2 - 本地修改版”。流程为标题页创建新存档 → 第一步填写存档名称 → 点击“创建完成” → 第二步填写个人AI调用ID（角色名）→ 确认并进入办公室 → 飞白“欢迎回来，角色名” → 角色“……休息日没睡好，早上有点晕。” → 原有后续剧情。只为新开场新增intro.welcome节点，旧intro及后续台词和分支保持不变。

存档默认名使用北京时间UTC+8和英文月份缩写，格式MMMdd-HHmm号计划，例如2026年10月15日12:30为Oct15-1230号计划；日期和小时分钟补零，不受Windows中文/英文显示语言影响。存档名与个人AI调用ID均可输入1—24个字符，去掉首尾空白，禁止空名与换行控制字符。

DemoProfile.name仍是存档名称，档案列表和办公室档案信息继续使用它；新增characterName保存角色名，剧情通过CharacterName与DialogueText进行称呼替换。旧档无characterName时沿用原name作为角色称呼，不会改名、重置进度或强制重新走建档流程。此前已播到旧intro及后续节点的档案维持原游标，不插播欢迎；新档进入office.intro时从intro.welcome开始。

第一步不写半成品档案；第二步姓名校验通过后，将两个名字一次写入同一份存档。上一步保留姓名草稿，取消后重新开始创建会生成新的默认计划名并清空角色草稿。存档写入失败时停留在创建页显示错误，不进入办公室。

实现：DemoFrontMenu负责两个页面；DemoSaveStore负责默认名生成、验证及双名字创建；DemoProgression负责旧档角色名兼容；DemoDialogueView使用角色名替换，不再把计划名称显示成主角名字。占位符替换为单次匹配，不会把玩家名字中恰好包含xxx或{player}的部分递归展开。

编辑器菜单“裁星计划 → 验证双阶段建档与角色名”验证默认名字、北京时间跨日、系统语言无关、空姓名拒绝、两种名字存档隔离、旧档兼容与开场顺序。Windows参数--profile-ui-check后接输出目录，可用独立测试档检查真实建档界面、返回/取消、空输入、欢迎与原台词显示、中途存档。本次不修改关卡与资源配置，上一版Excel的配置指纹不受影响。
