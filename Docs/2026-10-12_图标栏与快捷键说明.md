# 图标栏、资源列表与快捷键
一级功能改为底部七个小图标，默认收起二级菜单以扩大星图空间。鼠标悬停或键盘焦点进入图标时显示完整名称和键位；点击图标或按对应快捷键 → 打开同一功能菜单 → 再次点击或按同键收起。切换功能时同时更新选中高亮、标题与下级内容。
Q → 生产设施；W → 二级资源；E → 运输载体；R → 研发；T → 打击模块；Y → 作业投送；U → 资源申请。空格保持模拟暂停/继续。Esc先关闭下拉或二级菜单，再按Esc进入暂停菜单。文字输入、弹窗和下拉列表打开时屏蔽功能快捷键，Ctrl/Alt/Command组合也不会触发。
能源、物质、信息以小图标和数量固定列在左下；下方滚动列表继续展示各尺寸载体、已研发科技、各级武装及打击模块，保留未解锁、在造和在研状态。能源与物质同时显示每秒产出。点击基础资源显示说明及生产入口，点击其他库存沿用详情和制造跳转。
生产、研发、制造、投送、存读档及通关规则保持原有逻辑。界面切换与快捷键只管理菜单，不自动购买、发射、消耗资源或推进模拟。二级菜单和长列表仍支持鼠标滚轮。
一级图标使用DemoUiGlyph绘制工厂、立方体、火箭、烧瓶、准星、投送箭头和信封等图形；原有图片文件保持不变。各按钮保留ReplacementIcon位置，后续正式图标可替换；资源和储备继续使用原HUD图标配置。
