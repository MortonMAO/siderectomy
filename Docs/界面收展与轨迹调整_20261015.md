# 界面收展与轨迹调整

本次仅修改「本地修改版」的界面、视觉轨迹与验收代码，没有修改六关人口、节点、资源、制造费用、武装效果、任务时间及剧情选择条件。修改前源码备份在 ConfigBackups/20261015_HudPolish。

右侧信息栏默认展开，点击左沿的收起按钮或按 I 收起 → 右边缘保留左侧两圆角、右侧直角的「信息」页签，同时取消当前天体、节点或外逃舰的操作目标及高亮 → 点击天体重新选中并自动展开。单独按 I 展开而未选天体时显示星系总览与目录，不偷偷恢复旧目标。侦察成果和在途任务不变，星系探测仍可在没有目标时执行，定向侦察/打击必须重新选中。取消选中状态可保存恢复。信息文字保持顶部对齐和紧凑行距。

双栏均收起时，星图扩展到标题栏以下的整块画布，底部操作栏以浮层覆盖，不再留出右侧空带。任一右栏展开时，星图回到侧栏左侧的可用区域。星系中心和轨道按实际星图宽高重排，基地距离右边缘140、下边缘105个界面单位；不是把旧图简单拉到边缘。NPC普通通讯保留 AAA、BBB、暂停键与结束通讯四个选项，关键剧情选项仍由剧情系统单独控制。

本轮布局更新构建日志为 Docs/ExpandedMapBuild_Final_20261015.log；独立验收目录为工作区 Temp/ExpandedMapQA_Final_20261015、Temp/ExpandedMapNarrativeQA_Final_20261015 和 Temp/ExpandedMapOrbitQA_Final_20261015。收展时同步重建星图坐标和图片/名称位置，避免首帧出现星球与标注错开。源码备份为 ConfigBackups/20261015_ExpandedMap。旧存档没有 SelectionCleared 字段时默认为保留原选中状态，新存档明确记录取消选中；已有投送不撤回、不改时长。

通讯区默认折叠为右下边缘的 NPC 占位。点击占位或按 O 展开，有待处理剧情时恢复当前剧情，没有剧情时显示通讯状态；点击结束通讯或再次按 O 收起。关卡剧情、新手引导接入时自动展开 → 对话与选择仍经过原剧情保存接口 → 对话结束自动折叠。手动收起不会推进选择，剧情暂停逻辑保持不变；折叠后的待处理剧情仍需展开完成。

倒计时和倍速控件默认位于星图右上方、返回总览左侧。拖动倒计时数字或左侧握柄可移动整组控件，位置限制在画布内；暂停及 1×/2×/4×仍各自点击，不作为拖动区域。位置和收展状态为当前场景界面状态，不写入战役存档。

左下 Q–U 操作栏移除整块底板和顶部横线，按钮保持独立半透明浮动外观。行星图片从 24 放大至 48 个界面单位，月球与人工天体相应放大，原图保持原色，删除图下的彩色圆盘和泛光；局部预览使用同一批既有图片。恒星没有对应图片时保留基础圆形显示。

投送航线维持右下基地、绕中心逆时针、贴合椭圆巡航及恒星避让。径向转轨使用更平滑的过渡函数，边缘裁切使用平滑过渡；投送轨迹采用按弧长划分的 9 单位线段与 25 单位间隔，透明度约 15%。这些是视觉航迹，不是新增引力模拟，不改变在途结算时间、费用或命中效果。

构建入口仍为 DemoImportedConfigChecks.Build，运行时独立验收参数为 --hud-polish-check 和 --narrative-ui-check；测试使用各自输出目录的隔离存档，不覆盖玩家正式存档。轨迹检查增加四处分段连接的切线连续性断言。

验收结果：Docs/HudPolishBuild_Verified_20261015.log 构建成功，数值、建档、剧情与 128 方位轨迹检查通过。工作区 Temp/HudPolishQA_Verified_20261015/PASS.txt 与 Temp/HudPolishNarrativeQA_Verified_20261015/PASS.txt 均通过，包含实际射线点击、I/O 快捷分发、拖动边界、倍速与暂停、折叠后切换局部视图、剧情中途收起/恢复、两轮剧情结束自动折叠。此前发现的折叠状态下节点父按钮查询空引用已修复，剧情面板改为不透明并隐藏其后方的普通通讯内容。测试不是全关卡数值平衡通关。
