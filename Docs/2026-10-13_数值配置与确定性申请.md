# 确定性申请与数值配置
后续模块改版说明：模块制造已改为按manufactureSeconds倒计时入库，打击消耗能源+物质，科技消耗能源+信息；发射必须有模块库存。原即时预装配、双隐形、信息病毒、扰乱、窃取、解离及星系级打击已由《2026-10-13_模块制造与投送改版.md》中的现行规则替代。下文涉及这些旧规则的说明只作历史参考。
申请资源现在按配置等待后，固定拨付全部指定资源，不再随机选一种。默认每项增加100000，等待25游戏秒；只拨付本关已解锁的武装，申请计数、暂停、倍速和存档规则沿用原实现。未解锁载体和作业不会因资源申请而提前开放。该数额是大额有限库存，不是浮点无穷；资源充足后仍需制造载体、安排投送、等待航行。
全局配置入口是 Assets/Siderectomy/Resources/DemoRules.json。Unity菜单“裁星计划 → 配置表 → 打开全局数值规则”可以定位并打开；修改后保存，重开模拟生效。Windows程序需要重新构建以包含新的配置。关卡独立配置位于同目录DemoCampaign.asset，菜单“配置表 → 选中关卡参数”可以在Inspector调整。JSON的baseline是旧HTML参考数据，Unity关卡初始值由DemoCampaign.asset决定，不能通过改baseline调整Unity关卡。

| 配置区域 | 可调整内容 |
| --- | --- |
| application | seconds为等待秒数；amounts内energy/matter/info/a1/a2/a3为各项固定拨付量；unlockedArmsOnly控制是否过滤未解锁武装 |
| facilities | 设施费用、建造秒数、解锁；信息收集点productionRate为每座每秒产率 |
| batches | 三级武装费用、每批out产出、制造seconds、军工队列依赖 |
| carriers | 载体费用、制造seconds、航行flight、槽位slots、暴露exposure、解锁unlock |
| operations | 作业费用、执行seconds、人口伤害pop、中心比例伤害hp、固定HP伤害nodeDamage、暴露alert、熵增entropy、所需载体carrier |
| operations：特殊作业 | 扰乱duration持续秒数；窃取effect信息回收量；病菌interval周期、ticks次数、effect每次人口伤害；信息入侵duration限流时间、flowMultiplier流速倍率、useLimit次数上限（0不限）、effect备份伤害 |
| modules | 隐形费用、alert察觉修正、intercept拦截率修正（负数表示降低） |
| research | 研发费用、时间、解锁；高级武装校准effect为伤害倍率 |
| nodeTemplates | 政治、军事、能源、信息以及附属信息中心初始HP |
| layouts | 各关人口所在body及populationShare比例；species文明类型、regenerationRate恢复系数、scanExposureMultiplier侦察暴露倍率、chainSegments信息链段数；nodes列表的类型、数量count、模板template。第四关仅地球和月球人口，全部25节点在地球 |
| solarStory | enabled事件开关、eventSeconds首次离港时间、secondDelay首次选择至第二轮剧情的游戏秒数、reservedPopulation预留疏散人口及占位文案 |
| mechanics | 产能递减、拦截概率和损伤惩罚、协作减伤、节点影响科技/外逃的比例、备份和AI建造修正、校准奖惩、察觉阶段与AI权重 |
| ai | 设施建造点points、挂靠node、类型上限max、初始数量initialCount |
| DemoCampaign.asset | 每关时限、总人口、初始储备、基础产率、设施上限、科技与AI速度、外逃准备及飞离秒数、regenerationScale恢复倍率、玩家伤害倍率。nodeGate/protection仅兼容旧数据，已不参与伤害限制 |

节点伤害公式：伤害倍率 ×（最大HP × hp比例 + nodeDamage固定HP）×（1−协作减伤）。比如要让节点血量直接影响打击次数，可以将hp设为0、nodeDamage设为30；保留比例伤害时，即使把节点HP翻倍，需要的打击次数通常不变。这是伤害口径，不是配置没有生效。
配置同步到费用、进程计时和作业说明。预装配扣费入库 → 发射扣载体与模块库存，不重复收取原费用；隐形附加模块仍在发射时收费。已经开始的制造任务和在途作业保留提交时的倒计时；修改配置用于新模拟，不承诺旧存档里的既有伤害和进度回溯重算。
配置验收入口：“裁星计划 → 运行配置与资源申请验收”。它会实际修改一份规则副本并检查拨付量、等待、武装解锁过滤、节点HP、信息产率、打击伤害、作业时间、载体航行、扰乱持续、病毒周期和研发倍率，不只检查字段是否存在。
